How this was built

Synthetic transaction log generated in Python, analysed with pandas and scipy, cross-checked with DuckDB SQL, rendered here as hand-written SVG. Every number on this page is read from output/metrics.json — change the data and the page changes with it.

Data cleaning applied

    Known limits

    • The dataset is simulated, so effect sizes are plausible rather than observed.
    • Cohorts after month 11 are censored by the analysis window.
    • LTV is trailing revenue per acquired customer, not a predicted value.
    • Review themes are rule-tagged; a production version would classify with a model.
    Portfolio project. MetroBasket is a fictional business and the data is synthetic.
